# Архив как MCP-сервер

Свои созвоны, заметки и диктовки — с цитатами и отметками времени — доступны тому ассистенту, с которым вы и так работаете. Локально: сервер читает ту же базу, что и приложение, по stdio, и ничего никуда не отправляет.

Это то, чего не делает ни один облачный конкурент: у них расшифровки заперты в их собственном чате.

## Что он умеет

Только чтение. Инструмента, который что-то меняет или удаляет, в сервере нет — его ведёт модель, а модель, прочитавшая чужую страницу, не должна иметь возможности стереть запись.

| Инструмент | Что делает |
|---|---|
| `search_recordings` | Полнотекстовый поиск по архиву; возвращает список записей с идентификаторами |
| `list_recordings` | Последние записи, можно сузить до `meeting`, `note` или `dictation` |
| `read_recording` | Одна запись: `summary`, `transcript`, `source`, `screen`, `letter` или `all` |
| `find_moments` | Конкретные реплики по словам — с `[мм:сс]`, именем говорящего и записью, из которой взяты |

Документ длиннее 24 000 знаков приходит обрезанным, и в нём об этом сказано.

## Подключение

Сервер лежит внутри приложения после `Scripts/build.sh` и `Scripts/install.sh`:

```
~/Applications/LocalFlow.app/Contents/MacOS/localflow-mcp
```

Claude Code:

```bash
claude mcp add localflow-archive -- ~/Applications/LocalFlow.app/Contents/MacOS/localflow-mcp
```

Любой другой клиент — та же команда без аргументов, транспорт stdio:

```json
{
  "mcpServers": {
    "localflow-archive": {
      "command": "/Users/ВЫ/Applications/LocalFlow.app/Contents/MacOS/localflow-mcp"
    }
  }
}
```

## Что стоит понимать

Архив открывается **только на чтение**, поэтому сервер работает одновременно с приложением и не может повредить базу.

Содержимое записей — это реальные разговоры. Ассистент, которому вы дали этот сервер, увидит их целиком: подключайте его там, где это приемлемо. Сам сервер в сеть не ходит.

Цитаты `[мм:сс]` относятся к началу записи. Открыть этот момент можно в приложении — отметки в конспекте кликабельны.
