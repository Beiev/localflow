# Ревью LocalFlow 0.1.3 — 8 сентября 2026

## Главные исправления

1. **Длинная диктовка не вставлялась.** В архиве обнаружены завершённые записи длительностью 48 и 53,7 секунды. Обработку не отменяли: heuristic редактора отклонял предложение и ветка `needsReview` исключала вызов вставки. Окно уже было скрыто, поэтому пользователь не видел причину. Теперь подозрительная редактура сохраняется отдельно, для доставки используется детерминированная очистка исходника. В архиве есть именованная версия «Минимальная очистка». Пустой ответ или ошибка редактора также не лишают пользователя расшифровки. Исходная ошибка ASR этим не исправляется.
2. **Stop и Cancel разделены.** Повторное ⌘B завершает запись и скрывает панель, задача дочитывания аудио/редактуры продолжает работу. Нажатие во время финализации не отменяет задачу. Esc явно отменяет; аудио сохраняется. Строка меню показывает обработку. При проблеме вставки или безопасном fallback появляется панель результата на 10 секунд, затем доступ остаётся в меню/архиве.
3. **Прокрутка.** Удалены обрезание overlay до четырёх строк и прокрутка по непосчитанной высоте lazy-списка. NSScrollView/NSTextView обновляет изменившийся хвост, завершает layout и показывает конец. Корректно обрабатываются UTF-16 диапазоны и emoji. В основном окне отображается ограниченный хвост, архив хранит весь текст.
4. **Созвон одним действием.** Кнопка и левый ⌘⇧M запускают системное аудио и микрофон. Никакой формы перед стартом. Все приложения, кроме звука LocalFlow, попадают в системную дорожку. Shure MV7+ выбирается при наличии; иначе системный вход. Выходное устройство не меняется. Число голосов — автоматически, ручная корректировка доступна после записи. Тишина не запускает диаризацию без распознанных системных реплик.
5. **Интерфейс.** Основные настройки, модели и диагностика разделены. Поле стиля выровнено слева, диагностические строки убраны из повседневного экрана. Вся подсвеченная область навигации кликабельна. Заметка сначала создаётся как черновик; запись отдельной кнопкой. Название и описание сохраняются, повторная запись добавляет новые аудиочасти.
6. **Разрешения между обновлениями.** Старые ad-hoc сборки меняли code requirement, поэтому TCC показывал включённый тумблер, но отказывал процессу. Постоянная локальная подпись хранится вне Git. Повторные установки сохраняют requirement и доступ; доверенные системные корни не меняются.

## Дополнительные исправления предыдущего ревью

- Дисковое распознавание с checkpoint, полуоткрытой принадлежностью слов окнам, повторным контекстом и дочитыванием последнего фрагмента.
- Отказ открытия повреждённого архива показывает восстанавливаемую ошибку вместо аварии. Чтение SQLite проверяет ошибки шагов.
- Журнал аудио восстанавливает длины из файлов; запись и закрытие частей сериализованы. Изменение устройства не теряет сохранённые части.
- Старая задача автовыгрузки не выгружает только что используемую модель. Очистка ASR менеджера освобождает ресурсы; GPU-кеш ограничен.
- Сохраняются подтверждённые имена, вопросы с устаревшими источниками отменяются, ответ требует существующих ссылок. Проверка ссылок не является доказательством достоверности ответа.
- Установка отказывается заменять работающий процесс, проверяет подпись, сохраняет предыдущую сборку. Служебные .app остаются внутри noindex.

## Проверки

- Release build + строгая проверка подписи: успешно. Canonical app `~/Applications/LocalFlow.app`, bundle `com.beiev.localflow`, версия 0.1.3 (5).
- `Scripts/test.sh`: **32 core tests + 1 TextKit test**, без ошибок. Core включает 7 минут / 14 частей / 41 границу и последнее слово, checkpoint/resume, отказ редактуры с непустой доставкой, отдельное сочетание созвона. TextKit проверяет 3–120 строк и замену emoji без потери скролла.
- Через CUA: новый экран настроек, ввод слева, клик по пустому правому краю «Память», quiet draft заметки, реальный микрофон, начало созвона одной кнопкой. 21,9 секунды дали две отдельные дорожки Shure/system; на тишине нет текста. AirPods тогда отсутствовали, звук Mac шёл через встроенный выход.
- Пользователь ранее подтвердил физический старт/стоп ⌘B. Повторный аппаратный тест 40–60 секунд с вставкой после 0.1.3 запрошен; до ответа не считать принятым. Программная имитация левого Cmd через CUA не воспроизводила device-specific flags и не годится как доказательство.
- `edit-modes-013.json`: четыре результата без сети, 2,31–3,81 секунды. Предыдущий compose добавлял выдумки; новое правило на этих примерах их устранило. Нужен более широкий корпус.

- `long-dictation-013.json`: полный конвейер без сети на 115,77 с синтетической речи. ASR вместе с холодной подготовкой — 21,24 с, редактура — 6,63 с, память процесса около 2544 МБ. Редактор сократил повторяющиеся фрагменты, защита сработала: подготовлен непустой исходный текст с последними словами. Это не тест вставки в стороннее окно.

## Открытые риски

- Проверка редактуры эвристическая: может отклонять корректное сокращение отрицаний или перестановку чисел и пропускать другие изменения смысла. Fallback намеренно минимален, а не полноценная сильная редактура.
- Ввод в произвольные приложения ограничен их Accessibility. Фокус не переносится насильно; результат сохраняется, если поле изменилось.
- Во время обработки завершённой диктовки новая запись тем же shortcut пока не начинается. Текущая завершается; для отмены есть Esc. Нет скрытой отмены или замены результата.
- 4 похожих синтетических голоса ранее разделялись как 3. Сохранение профилей проверено на разных синтетических голосах, но человеческие перебивания и реальный двухчасовой созвон не приняты.
- Голос/стиль не должны оцениваться по двум примерам. Gemma 4 / Qwen3.5 пока кандидаты, см. отдельный документ; без замеров новый default не выбран.
- Системный захват включает уведомления/музыку других приложений. Удобство одного клика не означает автоматического выделения только разговора.
